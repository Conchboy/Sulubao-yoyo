搜狗皮肤 - 速录宝

## 文件夹说明
此文件夹包含速录宝输入法的动态搜狗魔改gif皮肤的相关资源文件。

## 文件列表

### 压缩包
- **搜狗.7z** - 搜狗皮肤完整压缩包
- **PicPackages.7z** - 图片资源包

### 图片资源
- **log312.gif** - 日志/标识动画312
- **log32.gif** - 日志/标识动画32
- **long.gif** - 长条动画
- **srzs.gif / srzs.png** - 相关状态动画和静态图片
- **ybf.gif / ybf.png** - 相关状态动画和静态图片
- **ybj.gif / ybj.png** - 相关状态动画和静态图片
- **zbf.gif / zbf.png** - 相关状态动画和静态图片
- **zbj.gif / zbj.png** - 相关状态动画和静态图片
- **zqf.gif / zqf.png** - 相关状态动画和静态图片
- **zqj.gif / zqj.png** - 相关状态动画和静态图片

## 使用说明
1. 解压 搜狗.7z 获取完整皮肤
2. 在速录宝输入法中导入使用
